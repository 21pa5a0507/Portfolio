## Overview

Professional backend and product engineering for Hexnode's enterprise Unified Endpoint Management product. This case study brings together three distinct workstreams: CIS compliance, Windows MDM customization, and microservice-based UEM modules.

The diagram and descriptions are conceptual. Internal infrastructure and proprietary source code are not disclosed.

## Problem

Enterprise endpoint management involves device configuration, security compliance, and production product capabilities. My work addressed these areas through compliance policies and scanning, Windows management customization, and backend product modules.

## My responsibilities

- Built CIS compliance policies and automated compliance scanning.
- Developed backend capabilities using Python, Django, REST APIs, and PostgreSQL.
- Implemented Windows MDM customization through CSP and ADMX integrations.
- Delivered microservice-based UEM product modules supporting managed devices in production.

## Technical implementation

### CIS compliance policies and scanning

Built Center for Internet Security compliance policies and automated scanning using Python, Django, REST APIs, and PostgreSQL. The work reduced unauthorized access risk by **25% based on internal CIS compliance benchmarks**. That figure describes an internal benchmark outcome, not a measured reduction in security incidents.

### Windows MDM customization

Implemented Windows MDM customizations using Configuration Service Provider (CSP) and ADMX integrations. The work improved enterprise configuration management efficiency by **60%**.

### Production UEM modules

Delivered microservice-based modules for Unified Endpoint Management supporting **1,000+ managed devices in production**. The scale refers to managed devices, not users, customers, or organizations.

## Results

- CIS work: **25% reduction in unauthorized access risk**, based on internal CIS compliance benchmarks.
- Windows MDM work: **60% improvement in enterprise configuration management efficiency**.
- UEM modules: support for **1,000+ managed devices in production**.

Each outcome belongs to its respective workstream. The figures should not be combined into a single product-wide performance or security claim.
