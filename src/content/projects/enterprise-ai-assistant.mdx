## Overview

An enterprise knowledge retrieval and workflow-support assistant developed as professional engineering work at Hexnode. The work combined LangChain, LangGraph ReAct agents, OpenAI APIs, retrieval engineering, and Jira integration.

This case study uses generalized descriptions and conceptual illustrations. It does not expose proprietary source code or internal infrastructure.

## Problem

The assistant supports enterprise knowledge retrieval and workflows connected to Jira. Retrieval latency and response accuracy were key areas of engineering improvement.

## My responsibilities

- Led end-to-end development of the enterprise RAG-based assistant.
- Built agent workflows using LangChain, LangGraph ReAct agents, and OpenAI APIs.
- Integrated knowledge retrieval and Jira workflow support.
- Improved retrieval using custom chunking and hybrid vector search with FAISS and Qdrant.

## Technical implementation

### Retrieval engineering

Custom chunking and hybrid vector search using FAISS and Qdrant were used to improve retrieval. The work delivered the latency and accuracy improvements reported below.

### Agents and workflow support

LangChain, LangGraph ReAct agents, and OpenAI APIs supported the assistant's knowledge and workflow capabilities. Jira integration connected the assistant with workflow support.

## Results

- **30% reduction in retrieval latency.**
- **40% improvement in response accuracy.**

These are the supplied outcomes for the professional assistant at Hexnode. They are not benchmarks for HexPilot or for the portfolio website.
